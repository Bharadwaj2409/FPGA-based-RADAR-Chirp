RADAR Chirp Engine

RADAR Chirp Engine is an FPGA-based RADAR waveform generation project that generates a programmable linear frequency chirp directly in FPGA hardware. The project uses Vitis HLS, Vivado, Xilinx DDS Compiler, and a Zmod AWG DAC to take a mathematical RADAR waveform and implement it as an actual analog signal. The chirp parameters can be configured based on the required waveform, including sampling frequency (f s),starting frequency (f0), bandwidth (B), chirp time (Tc), guard time (Tg), idle time (Ti), number of chirps, and number of samples per chirp.

The chirp generator was implemented in C/C++ using Vitis HLS. The waveform follows the standard LFM chirp equation, where the chirp slope is k=B/Tc, the phase is given by ϕ(t)=2π(f0t+0.5kt2), and the output waveform is x(t)=cos(ϕ(t)). During the active chirp period, the frequency increases linearly with time, while the output is set to zero during the guard and idle periods. The HLS implementation generates the waveform sample-by-sample, with the processing loop pipelined using #pragma HLS PIPELINE II=1 to target an initiation interval of one clock cycle.

A separate waveform-generation path was also implemented using the Xilinx DDS Compiler, providing a comparison between a custom HLS-based implementation and a dedicated FPGA waveform-generation IP. For the HLS implementation, the generated waveform passes through the FPGA datapath and Zmod AWG controller before being sent to the Zmod DAC, producing the corresponding analog chirp output. The DDS implementation similarly routes the DDS output through the Zmod AWG controller to the DAC.

The main objective of the project was to work through the complete process of taking a mathematical RADAR waveform and implementing it in real FPGA hardware. Rather than generating the chirp only in software, the project demonstrates the complete HLS → Vivado → FPGA datapath → DAC workflow and allows the resulting waveform to be observed using external test equipment
